# Get a ServCat fixed list

Get a ServCat fixed list

## Usage

``` r
get_fixed_list(endpoint, secure = FALSE, api_key = NULL, rename_key = TRUE)
```

## Arguments

- endpoint:

  Fixed-list endpoint name.

- secure:

  Logical. Use the secure API?

- api_key:

  Optional secure API key.

- rename_key:

  Logical. Rename a `key` column to `code`?

## Value

A tibble.
