# Build a clean restricted-resource message

Build a clean restricted-resource message

## Usage

``` r
restricted_resource_error(reference_id, resource_id = NULL, secure = FALSE)
```

## Arguments

- reference_id:

  A ServCat reference ID.

- resource_id:

  Optional ServCat resource ID.

- secure:

  Logical. Is the secure API being used?

## Value

A clean character scalar.
