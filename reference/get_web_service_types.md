# Get valid ServCat web service types

Retrieves the fixed list of Web Service, or Linked Resource, types used
by ServCat.

## Usage

``` r
get_web_service_types(secure = FALSE, api_key = NULL)
```

## Arguments

- secure:

  Logical. Use the secure API?

- api_key:

  Optional secure API key.

## Value

A tibble with web service type choices.
