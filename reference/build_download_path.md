# Build a safe output path for a downloaded ServCat file

Build a safe output path for a downloaded ServCat file

## Usage

``` r
build_download_path(path, file_name, resource_id, overwrite = FALSE)
```

## Arguments

- path:

  Output directory.

- file_name:

  File name from the ServCat API.

- resource_id:

  ServCat resource ID.

- overwrite:

  Logical. Overwrite existing files?

## Value

A length-1 character vector.
