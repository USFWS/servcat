# Get the current ServCat application version

Retrieves the current ServCat application version from the service
metadata endpoint.

## Usage

``` r
get_service_version(secure = FALSE, api_key = NULL)
```

## Arguments

- secure:

  Logical. Use the secure API?

- api_key:

  Optional secure API key.

## Value

A length-1 character vector with the current ServCat application
version.
